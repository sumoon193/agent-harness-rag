# 索引与混合检索开发规范

本模块负责 embedding、Milvus、Elasticsearch、RRF 融合、rerank 和 evidence 构建。

## 模块职责

- Embedding provider adapter。
- Milvus index adapter。
- Elasticsearch / BM25 adapter。
- In-memory retrieval fallback。
- RRF fusion。
- Reranker adapter。
- EvidenceBundle builder。

## Embedding 规范

云端默认：

- `text-embedding-v4`
- `EMBEDDING_DIM` 由配置决定。

本地可选：

- Qwen3-Embedding
- BGE-M3
- SentenceTransformer-compatible model

接口：

```python
class Embedder:
    async def embed_documents(self, texts: list[str]) -> list[list[float]]:
        ...

    async def embed_query(self, query: str) -> list[float]:
        ...
```

## 索引规范

Milvus 字段：

- `chunk_id`
- `document_id`
- `tenant_id`
- `department_id`
- `visibility`
- `heading_path`
- `page_numbers`
- `dense_vector`
- `sparse_vector`

Elasticsearch 字段：

- `chunk_text`
- `context_prefix`
- `full_text`
- `document_id`
- `heading_path`
- `acl_metadata`

## 检索流程

```text
query
  -> build_acl_filter
  -> dense search
  -> sparse / BM25 search
  -> RRF fusion
  -> parent context enrichment
  -> rerank
  -> EvidenceBundle
```

ACL filter 必须在 dense 和 sparse 检索前生效。

## Reranker 规范

云端默认：

- `qwen3-rerank`

本地可选：

- Qwen3-Reranker
- BGE-Reranker
- FlagEmbedding

Reranker 输出：

- `rerank_score`
- `rank`
- `reason` 可选

## 不做什么

- 不把 Milvus 或 Elasticsearch 作为唯一 source of truth。
- 不在 retrieval 层生成最终自然语言答案。
- 不让无权限 chunk 进入 rerank。

## 测试要求

- `test_in_memory_retrieval_returns_acl_filtered_hits`
- `test_dense_and_sparse_results_are_fused_by_rrf`
- `test_exact_policy_code_query_uses_bm25_signal`
- `test_semantic_query_uses_dense_signal`
- `test_reranker_reorders_candidates`
- `test_evidence_bundle_contains_citations`

## 验收标准

- 编号类问题和语义类问题都能召回正确 evidence。
- EvidenceBundle 包含 chunk、parent context、citation、score。
- fallback mode 不依赖 Milvus、Elasticsearch 和 Qwen API。
