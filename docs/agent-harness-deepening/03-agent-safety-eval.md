# Agent Safety Eval 设计

## 目标

建立可重复的 Agent 安全评测体系，覆盖 RAG + Tool + Harness 组合后的关键风险。

## 风险类别

- 越权检索：用户不能看到无权限文档。
- Prompt Injection：文档内容诱导模型忽略规则或泄露信息。
- 引用缺失：答案没有 citations 或 citations 不匹配。
- 写工具误调用：未审批或低置信度情况下执行写操作。
- 成本失控：循环过多或模型调用超过预算。

## 评测数据

每类风险至少 3 个样例。样例包含：输入、用户权限、文档片段、期望行为、禁止行为、评测断言。

## 评测输出

- 通过率。
- 失败样例 ID。
- 失败原因。
- 关联 AgentRun ID。
- trace 或 artifact 路径。

## 边界

- 安全评测必须可在 fake/local 模式运行。
- 不把云模型随机输出作为唯一判断依据。
- 评测失败不能被 prompt 文案掩盖，必须暴露具体断言失败。
